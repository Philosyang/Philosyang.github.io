```python
class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        n = len(cost)

        @lru_cache(None)
        def stepUp(index: int) -> int:
            if index >= n:
                return 0
            return cost[index] + min(stepUp(index + 1), stepUp(index + 2))

        return min(stepUp(0), stepUp(1))
```

the key is to find a way to put `running_cost` outside of the parameters so that we can memoize the function -> "parameters should describe the remaining subproblem, excluding the path you took to get here."
